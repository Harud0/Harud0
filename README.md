CONFIGURAÇÃO DA SNAKE CONTRIBUTION
=========================================================

Para habilitar a animação, crie o arquivo:

.github/workflows/snake.yml

no repositório Harud0/Harud0, com o conteúdo abaixo.
Este workflow é um arquivo separado e NÃO deve ser colado
dentro do README.md.

---------------------------------------------------------
name: Generate Snake

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:
  push:
    branches:
      - main

permissions:
  contents: write

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - name: Generate contribution snake
        uses: Platane/snk@v3
        with:
          github_user_name: Harud0
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - name: Publish to output branch
        uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

---------------------------------------------------------

PASSOS:
1. Crie a pasta .github/workflows no repositório.
2. Crie snake.yml com o workflow acima.
3. Confirme que Actions está habilitado no repositório.
4. Em Settings > Actions > General, verifique as permissões
   necessárias para o workflow escrever conteúdo.
5. Execute o workflow manualmente pela aba Actions.
6. Após a execução bem-sucedida, confira se a branch output
